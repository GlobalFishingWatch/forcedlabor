# forcedlabor: Global Fishing Watch's forced labor risk machine learning algorithm

forcedlabor is an R package containing the codes to classify the risk of
forced labor on fishing vessels via a machine learning algorithm trained
on a combination of known forced labor cases and AIS data predictors.
